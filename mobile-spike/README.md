# mobile-spike: Sound Local wrapped as an Android app (Capacitor)

A throwaway proof that the existing web build runs inside a native Android shell. It has its own
`package.json`; nothing in `src/`, the root `package.json` or `vite.config.js` was changed.
Findings feed `docs/research/mobile-app/FEASIBILITY.md` (section 8).

### What the API result means

The web game calls `fetch('api/otter')` and `fetch('api/stt')` with relative paths. In a Capacitor app the
page origin is `https://localhost` (Android) or `capacitor://localhost` (iOS), so these must become absolute
URLs to the hosted backend, and the Vercel functions must answer CORS preflights for those two origins.
Small change, but in `src/` and `api/`, so it was left for the owning lane. Pointing Capacitor's
`server.url` at the live site would also "work" but is a worse idea: the app would be an online-only
website in a frame, which is what Apple guideline 4.2 / 2.5.2 rejects.

## Reproduce

Needs Node 22+ (`source ~/.nvm/nvm.sh && nvm use 24` on this VM), JDK 21, Android SDK (platform 36,
build-tools 36.0.0, platform-tools, emulator, `system-images;android-36;google_apis;x86_64`).

```sh
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 ANDROID_HOME="$HOME/Android/sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
npm ci                       # repo root
npm --prefix mobile-spike ci
cd mobile-spike && npm run build:android   # vite build -> cap sync android -> gradlew assembleDebug
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.soundlocal.mobilespike/.MainActivity
```

Gotcha: Maven Central (`repo.maven.apache.org`) returned **HTTP 429 Too Many Requests** to this VM for
several attempts. Fix without changing the project: a user-level Gradle init script
(`~/.gradle/init.d/mirror.gradle`) that swaps that URL for Google's mirror
`https://maven-central.storage-download.googleapis.com/maven2/`.

Debug a running app from the desktop: `chrome://inspect`, or
`adb forward tcp:9333 localabstract:webview_devtools_remote_<pid>`.

## What is in here

- `package.json` / `package-lock.json`: Capacitor 8.6.2 (`@capacitor/core`, `@capacitor/android`, `@capacitor/cli`).
- `capacitor.config.json`: app id `com.soundlocal.mobilespike`, `webDir: "../dist"`, no `server.url`.
- `android/`: generated by `npx cap add android`, plus `RECORD_AUDIO` and `MODIFY_AUDIO_SETTINGS` in
  `AndroidManifest.xml`. Capacitor's `BridgeWebChromeClient.onPermissionRequest` (lines 101-124 in 8.6.2)
  turns the page's mic request into the Android prompt, so no plugin was needed.
- Build outputs, APKs, synced web assets, `local.properties` and `node_modules` are git-ignored.

## iOS (not built: needs a Mac)

iOS builds need macOS with Xcode 26+ (Capacitor 8 targets iOS 15+). Steps when a Mac or cloud Mac is available:
`npm i @capacitor/ios@8.6.2 && npx cap add ios`, add `NSMicrophoneUsageDescription` to `Info.plist`
(the app crashes on mic access without it), set a signing team (Apple Developer Program, US$99/year) and
run on a device or TestFlight. Cloud options: Expo EAS, Codemagic, GitHub macOS runners, Xcode Cloud.
On iOS, also add an audio-session plugin so sound plays with the silent switch on.
