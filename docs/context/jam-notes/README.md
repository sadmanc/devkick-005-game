## The 6 facts that matter most

1. It is **today, Sat Nov 14, 2026, 1-6pm**, UofT Bahen Centre room BA1220 (40 Willcocks St). Build time
   on Luma is 2:00-4:30pm; the official page says **presentations at 5pm** (presenting = entering). Luma shows it **full, waitlist**.
2. It is **not Roblox**. The games go to the Chroma Awards, whose game rules say "playable on web without
   requiring a download" at a public link. Build a browser game.
3. Run by **devkick** (Yohann and Jenny Calpu; Yohann is a Devin Ambassador and lists Cognition as his
   work). Sponsor: Cognition. Partners: UTMIST, ElevenLabs, Meshy, Modal, Chroma Awards.
4. devkick's one rule of taste: **"demo or it didn't happen."** A game that runs in front of them beats
   any idea.
5. Prize: the #1 team is **fast-tracked to the semifinals** of the Chroma category they pick. Chroma
   then pays $2,000 per category win, plus tool awards (ElevenLabs $22,000 pool, Meshy $11,000 pool,
   Meshy Game of the Year trip to the gala).
6. Yohann built a model jam game four weeks ago: **Downhill**, a 3D browser bike game made with Devin,
   Meshy, ElevenLabs, Rosebud and Modal. It shows what he thinks a great Devin game looks like.
