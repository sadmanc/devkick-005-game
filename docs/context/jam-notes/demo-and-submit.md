# Demo script and submission checklist

## 2-minute demo (shape, adjust to the game)
1. **0:00** One sentence: what the game is and its Chroma category.
2. **0:10** QR code on screen; judges join on their phones. Start a round immediately. Let it play out;
   don't talk over the announcer.
3. **1:10** One slide, "How it was built": the four tools, each with a number (Devin sessions/PRs/
   reviews/tests, Meshy models, ElevenLabs voice lines and live lines made during this demo, Modal jobs).
4. **1:40** One sentence on who did what ("I directed; Devin wrote every line").
5. **1:50** "It's live at <url> and submitted to Chroma tonight." Leave the QR up.
- Have a **backup recording** of a full round in case the Wi-Fi fails.

## Chroma submission checklist (submit.chromaawards.com)
- [ ] Public web link, no download, not private/unlisted/password (Cloudflare Pages or Vercel).
- [ ] Gameplay video uploaded with a download link.
- [ ] One category chosen.
- [ ] All in-game text in English.
- [ ] Tools tagged with proof: Devin, ElevenLabs, Meshy, Modal (screenshots of generations, PR list).
- [ ] Original assets only; credit anything else and confirm its licence.
- [ ] Submitter 18+.
- [ ] Post on social, tagging Chroma Awards and each tool (Submission of the Day).
- [ ] Optional second entry: Behind-the-Scenes: Game Division video (1-10 min).
- [ ] Deadline Jan 7, 2027, 11:45pm PT; the game can keep improving until then.
